# Security Policy

## Reporting Security Issues

The Tokenetes maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/tokenetes/tokenetes/security/advisories/new) form.

For more details, see the [Tokenetes security policy](https://github.com/tokenetes/tokenetes/blob/main/SECURITY.md).
